# 🎵 கர்நாடக சங்கீத அறிமுறை தரம் 2 (Carnatic Music Theory Grade 2)
### Sahitya Sruthilaya Music College Syllabus Interactive Learning & Trial Exam Portal

An interactive, kid-friendly web application designed to help young Carnatic vocal students master Grade 2 Music Theory and excel in their written exams.

---

## 🌟 Key Features

1. **📖 பாடக் குறிப்புகள் (Comprehensive Study Notes)**:
   - Detailed definitions, origins, and explanations for all 6 syllabus units in both **Tamil** and **English**.
   - Interactive **12 Swarasthana Keyboard** with real audio synthesis (Web Audio API).
   - Audio demonstration of all 7 Sapta Swaras with animal/bird mnemonics.
   - Tala structure tables and hand gesture guides.

2. **💡 நினைவு அட்டைகள் (Flashcards Mode)**:
   - 22+ flashcards covering every definition, Sanskrit term, Tamil name, and formula.
   - Flip-to-reveal answers with keyboard and touch support.
   - Shuffle and filter controls for rapid revision.

3. **🎯 பலவுள் தெரிவு வினாக்கள் (MCQ Quiz Practice)**:
   - 28+ multiple-choice questions with immediate answer feedback.
   - Detailed explanations and streak tracking.
   - Filter by individual syllabus topics or practice all at once.

4. **✍️ எழுத்துப் பயிற்சி (Write / Type Practice - Small Questions)**:
   - Specifically built for repeated question-answer practice.
   - Prompts small, targeted questions.
   - Students can type their answer in Tamil or English transliteration (e.g. typing `குரல்` or `kural`).
   - Includes hint button, model answer reveal, and self-evaluation grading ("Got it right", "Needs practice", "Repeat later").

5. **📝 மாதிரிப் பரீட்சை (Authentic 100-Mark Trial Exam)**:
   - Full 30-minute timed exam simulation mirroring the real academy paper:
     - **Part A:** 10 MCQs (20 Marks)
     - **Part B:** 10 Fill in the Blanks (20 Marks)
     - **Part C:** Match the Following (10 Marks)
     - **Part D:** Tala Akshara Calculations (20 Marks)
     - **Part E:** Short Answer Questions with Rubrics & Model Answers (30 Marks)
   - Detailed score card with percentage, letter grade (Distinction, A, Pass), and celebratory confetti!

6. **🖨️ அச்சு வினாத்தாள் (Printable Exam Sheet)**:
   - One-click print-ready A4 question paper with lined blanks for handwritten practice with a pen.

7. **🪕 உள்ளமைந்த சுருதிப் பெட்டி (Built-in Tanpura Drone)**:
   - Synthesizes realistic Indian tanpura drone (Pa-Sa-Sa-Sa) in any pitch (C, C#, D, D#, E, F, G, A / 1st to 6th Kattai) using pure Web Audio API without any external dependencies!

8. **📜 அசல் புத்தகப் பக்கப் பார்வை (Original Syllabus Viewer)**:
   - One-click view of the uploaded page from the textbook (*Sahitya Sruthilaya Music College - Page 4*).

## 💻 Running Locally (Offline)
Simply open `index.html` in any web browser (Chrome, Safari, Firefox, Edge):
- **Mac:** Double-click `index.html` or run `open index.html`
- **Windows:** Double-click `index.html`

Or serve with Python:
```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.
